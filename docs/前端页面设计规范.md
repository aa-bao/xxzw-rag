# 前端设计编码规约（Apple 风格）

## 1. 适用范围与设计基调

本规约适用于"想象之外"公司内部管理系统的所有前端页面。技术栈固定为**Vue 3 + TypeScript + Tailwind CSS + Motion for Vue（@vueuse/motion）**。新页面、新组件、页面改造一律按本规约执行，禁止沿用历史页面的旧样式。

**设计基调**：浅色模式、Apple 硬件质感（Mac Studio 风格）、玻璃拟态（Glassmorphism）、高精度数据可视化。目标不是"用 Tailwind 做出来的后台"，而是原生、有物理质感、流体的 macOS 桌面级应用。

**绝对禁止**：

- 传统的 Bootstrap 默认后台模板样式，ai 味的紫色渐变（`#8B5CF6` 系、`purple-500`
  系，尤其禁止大面积渐变背景搭配紫色高亮）。
- 纯黑 `#000000` 与纯白 `#FFFFFF` 作为背景色或大面积表面色。
- **emoji 与文本符号冒充图标**（详见第 7 节）：UI 中任何图标、状态、按钮、占位
  一律用图标组件，禁止 `✅`、`⚠️`、`🚀`、`→` 等字符。

### 1.1 优先级

生成代码时遇到本规约内两条规则冲突，按以下优先级裁决：

1. 光效与玻璃材质（毛玻璃、透明层）——材质错了页面质感立即崩塌；
2. 动效物理（弹簧、可打断、按压反馈）——这是 Apple 风格区别于普通后台的核心；
3. 排版层级（字号、字重、字距）——数值展示的精密感依赖排版；
4. 布局与语义化——不破坏以上三者的前提下保证结构正确。

### 1.2 参考物

- 视觉参考：`想象之外 Beyond Imagination Dashboard (Mac Studio Edition)` 单文件demo。布局、配色、玻璃卡片、图表风格以其为准，但交互部分按本规约第 4 节替换为弹簧物理，不得沿用其 CSS transition。
- 动效参考：Apple Design skill（来自 WWDC *Designing Fluid Interfaces*、*The
  Details of UI Typography* 等，经 Emil Kowalski 翻译到 Web）。

## 2. 设计令牌（Design Tokens）

所有颜色、字体、圆角、阴影只允许引用令牌。**禁止硬编码色值**，禁止使用`bg-blue-500`、`text-gray-400` 等 Tailwind 默认色。

### 2.1 背景

```css
--bg-base:        #F5F5F7;                      /* 页面主背景，全局唯一背景色 */
--bg-subtle:      #FAFAFC;                      /* 次级背景：分组、井状区域 */
--bg-glass:       rgba(255, 255, 255, 0.72);    /* 玻璃卡片/侧栏表面 */
--bg-glass-strong: rgba(255, 255, 255, 0.85);   /* 可悬停浮层（弹窗） */
--bg-elevated:    #FFFFFF;                      /* 不透明高优先级表面（顶部栏内元素） */
```

> 玻璃表面与背景必须拉开明度差：玻璃面用 `rgba(255,255,255,…)` 白色半透明覆盖在`#F5F5F7` 底上，自然形成可辨识的层级。禁止在浅色半透明表面上再叠另一块浅色半透明表面（对比度会塌掉）。

### 2.2 边框与阴影

```css
--border-subtle:        rgba(0, 0, 0, 0.06);    /* 卡片描边，全局统一 */
--border-strong:        rgba(0, 0, 0, 0.10);    /* 强调描边：输入框、选中态 */
--shadow-card:          0 10px 30px -5px rgba(0,0,0,0.04), 0 0 1px 1px rgba(0,0,0,0.02);
--shadow-card-hover:    0 20px 40px -10px rgba(0,0,0,0.08), 0 0 1px 1px rgba(0,0,0,0.04);
--shadow-modal:         0 25px 60px -12px rgba(0,0,0,0.18), 0 0 1px 1px rgba(0,0,0,0.04);
```

- 卡片描边统一 1px `--border-subtle`，**不用**纯白高光描边。
- 阴影统一弥散多层（ambient + 1px contact），**禁止**大范围 `box-shadow` 硬投影。

### 2.3 文本

```css
--text-primary:   #1D1D1F;                      /* 主文本、KPI 大数字 */
--text-secondary: #86868B;                      /* 次级文本、标签、图例 */
--text-tertiary:  #AEAEB2;                      /* 占位符、禁用、时间轴刻度 */
```

文本全部落在不透明深灰上，**禁止**在玻璃面使用浅灰/白色文本。

### 2.4 品牌与状态色

```css
--accent-blue:    #007AFF;                      /* 主操作色、选中态、图表主线 */
--accent-indigo:  #5856D6;                      /* 次图表线、信息标记 */
--accent-orange:  #FF9500;                      /* 警告、中性图表线 */
--accent-green:   #34C759;                      /* 成功、在线、正向趋势 */
--accent-red:     #FF3B30;                      /* 错误、危险操作 */
```

**禁止**额外引入自定义色。需要新语义时，在现有六色中复用或向作者申请扩展令牌。

### 2.5 圆角

```css
--radius-lg: 0.875rem;    /* 14px：按钮、输入框、标签 */
--radius-2xl: 1rem;       /* 16px：次级面板 */
--radius-3xl: 1.25rem;    /* 20px：卡片、侧栏条目、弹窗 */
--radius-full: 9999px;    /* 胶囊：Badge、开关、状态点 */
```

圆角沿连续曲率走向，**禁止** `rounded-sm`/`rounded-md` 等小圆角破坏观感。

### 2.6 间距

统一按 4px 网格递进：`4 / 8 / 12 / 16 / 20 / 24 / 32`。卡片内边距 `p-5`（20px），
页面主区边距 `p-6`（24px），卡片间距 `gap-5`（20px）。卡片与文字对齐时，内边距必须与相邻元素的 x 轴 padding 一致，杜绝文字"顶到卡片边"。

### 2.7 图标

图标统一使用 **Element Plus 图标库**（`@element-plus/icons-vue`）。图标是 UI 的一等公民，**禁止**用 emoji、字符符号或网络图片代替。

- 图标用 `<el-icon>` 包裹，用 `currentColor` 继承所在元素文本色，禁止固定为某个色值。库内图标为填充风格（`fill="currentColor"`）；需要描边/线性风格时，用内联 SVG（`fill="none"` + `stroke="currentColor"`）替代。
- 尺寸统一：按钮内 `16px`，卡片图标徽标内 `20px`，空状态 `48px`（用 `font-size`控制）。行内图标与文字垂直居中，间距 6px。
- 库内找不到语义匹配的图标时，内联一个自定义 SVG 描边图标（heroicons 线性风格，`fill="none"` + `stroke="currentColor"`），不得降级为 emoji。
- 无意义装饰性图标（仅为了"有图标"而加）禁止出现。

## 3. 排版与字体

### 3.1 字体栈

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display",
             "PingFang SC", "Helvetica Neue", sans-serif;
```

系统字体优先，优先顺序固定为 `-apple-system` → `BlinkMacSystemFont` → SF Pro
Display → PingFang SC，**禁止**引入 Inter、Roboto 等自定义字体。

### 3.2 数字与等宽数字

**所有数值型数据**（KPI、百分比、FLOPS、延时、时间戳）强制：

```css
font-variant-numeric: tabular-nums;
```

防止数字实时刷新时宽度跳动。时间与阈值标注（如 `⌘K`）用等宽字体`SF Mono, Menlo, Monaco, monospace`。

### 3.3 字距与行高（tracking / leading）

字距随字号变化，**禁止**全文统一 `letter-spacing`：

| 用途             | 字号                      | 字距          | 行高  |
| -------------- | ----------------------- | ----------- | --- |
| 页面标题 H1        | `text-2xl`（24px）        | `-0.02em`   | 1.2 |
| 卡片标题 H3        | `text-base`（16px）       | `-0.01em`   | 1.3 |
| 正文 / 描述        | `text-xs`~`text-sm`     | `0`         | 1.5 |
| 微型标签（FLOPS、状态） | `text-[10px]`~`text-xs` | `0.03em`，大写 | 1.4 |

字号层级固定为：微型标签 `10-12px` → 正文 `12-14px` → 卡片标题 `16px` →页面标题 `24px`。**禁止** KPI 数值用小于 `text-2xl` 的字号。

### 3.4 语义化排版

- 卡片内文字至少两级：`text-secondary` 标签 + `text-primary` 数值/标题。
- 层级靠**字重**拉开（`font-medium`/`font-bold`/`font-black`），不只靠字号。
- 数值前导趋势（`↑ 12.5%`）用 `--accent-green` 的 `font-bold` 小字，不带箭头以外的符号。

## 4. 动效与交互物理（Apple 法则）

**最高优先级指令：所有交互元素禁止使用 CSS `transition` 和 `@keyframes` 实现动效，必须使用弹簧物理（Spring Physics，Motion for Vue）。** 唯一例外是第 4.5 节的按下反馈 `:active` 变换，以及第 6 节减弱动态效果后的兜底。

弹簧双参数：**damping**（阻尼，`1.0` 临界无回弹，`<1.0` 欠阻尼会回弹）与**response**（秒，越小越快；不是 duration，弹簧没有固定时长）。

### 4.1 默认动效参数

```ts
// Motion for Vue
import { useSpring } from '@vueuse/motion';

// 临界阻尼，优雅快速落位：弹窗出现、菜单展开、数字跳动
useSpring(el, {
  y: 0,
  type: 'spring', bounce: 0, duration: 0.4,
});

// 带动量交互（拖拽松手/滑动后）：允许轻微回弹，体现惯性
useSpring(el, {
  y: target,
  type: 'spring', bounce: 0.2, duration: 0.4,
});
```

| 交互              | damping | response  |
| --------------- | ------- | --------- |
| 默认 UI（出现/消失/换位） | `1.0`   | `0.3–0.4` |
| 底部抽屉 / 侧滑面板     | `0.8`   | `0.3`     |
| 旋转              | `0.8`   | `0.4`     |
| 拖拽松手后的惯性回弹      | `0.8`   | `0.4`     |

### 4.2 可打断性（最核心）

任何动画必须随时可打断、可重定向：

- 动画**永远从当前屏幕上的真实位置**开始（presentation value），禁止从目标值/逻辑值起步，否则会产生可见跳变。
- 弹窗关闭动画进行中用户再次点击，必须立即从当前位置反向弹回，不能等待播完或
  生硬跳回起点。
- 拖拽手势反转时，速度要**混合过渡**（spring 库带速度重定向），不能硬切造成"撞墙"感。
- 手势路径全程不得锁定输入。

### 4.3 响应性与直接操控

- **按下即反馈**：视觉反馈在 `pointerdown` / `:active` 瞬间触发，禁止等待 `click`
  抬起。
- **按压缩放**：所有可点击卡片、按钮按下瞬间轻微缩小。

```css
/* CSS 兜底（作用于 active 瞬间，随后由弹簧接管位移） */
.btn:active { transform: scale(0.97); }
```

- 拖拽元素用 Pointer Events + `setPointerCapture` 保证 1:1 跟手，并记录 grab offset
  与速度历史；松手时把释放速度交给弹簧作为初始速度（seamless 速度交接）。
- 列表、面板、抽屉用**动量投影**落位（释放速度投影出目标停靠点，再吸附最近吸附点），
  禁止从松手点硬吸附最近边界。

### 4.4 触觉反馈分层

| 反馈   | 触发时机           | 实现                             |
| ---- | -------------- | ------------------------------ |
| 按压缩放 | `pointerdown`  | `:active scale(0.97)`          |
| 悬停上浮 | `pointerenter` | 弹簧 `y: -2px` + 阴影加深            |
| 内容进入 | 路由/挂载          | 弹簧 `y: 8px → 0` + `opacity` 淡入 |
| 数值跳动 | 数据更新           | 弹簧数字滚动 / `tabular-nums` 稳宽     |

### 4.5 悬停

卡片悬浮统一：弹簧上浮 `y: -2px`，阴影由 `--shadow-card` 过渡到 `--shadow-card-hover`，
描边不透明度不变。**禁止**悬浮时整体放大（scale 仅用于按下）或改变背景色。

## 5. 玻璃拟态材质

### 5.1 玻璃面板

```css
.glass-surface {
  background: var(--bg-glass);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid var(--border-subtle);
  box-shadow: var(--shadow-card);
}
```

- **侧栏、顶栏、卡片、弹窗**统一用该玻璃表面；顶栏玻璃 `blur(20px)` 高度透出下方
  滚动内容。
- 弹窗等浮层用 `--bg-glass-strong`，模糊更强、阴影更深（`--shadow-modal`）。
- 表面越重，层级越接近结构边界（侧栏比按钮重）；**禁止**在另一块浅色玻璃上叠浅色
  玻璃。

### 5.2 背景环境光

主内容区背后放 2–3 个弥散光斑（`.blur-[120px]`、`rounded-full`、`pointer-events-none`、`bg-blue-100/60` 与 `bg-purple-100/50`），营造玻璃折射的光线感。光斑颜色必须用**极低饱和度的浅色调**（`blue-100`、`purple-100` 级别），禁止高饱和光斑。

## 6. 无障碍与边界

- **减弱动态效果**：监听 `@media (prefers-reduced-motion: reduce)`，所有弹簧/位移动画替换为 200ms 透明度交叉淡入淡出，去掉回弹与位移动画。
- **降低透明度**：`@media (prefers-reduced-transparency: reduce)` 时玻璃表面改为近实底（背景不透明度升至 0.9+，`backdrop-filter: none`）。
- **对比度**：玻璃面上正文对背景对比度 ≥ 4.5:1。玻璃表面保持浅色 + 深灰文本，禁止浅灰/白字；必要时给悬停浮层加深阴影分隔背景。
- 尺寸单位用 `rem`，随用户文字大小缩放布局；不做纯 px 硬排。

## 7. 核心组件规范

组件基线（数据示例沿用系统业务）：

- **指标卡 StatCard**：标签（`text-xs` secondary）→ 图标徽标（28px 圆角方，色相 10% 透明底 + 同色 `<el-icon>` 图标）→ 数值（`text-2xl font-black`主色）→ 趋势（绿/橙 `font-bold` 小字）→ 底部迷你贝塞尔趋势线（同色 2.5px圆头描边）。整卡可点击，按 4.5 悬停。图标不得用 emoji 或字符。
- **图表卡 ChartCard**：纯 SVG 平滑贝塞尔样条，面积渐变（顶部同色 20% 到 0%），仅水平虚线网格（`rgba(0,0,0,0.04)`），**禁止**垂直网格线；图例 = 色点 + `text-xs`标签。折线图悬浮召唤垂直十字线与玻璃 Tooltip，Tooltip 弹簧**磁吸**最近数据点。
- **数据表格 DataTable**：表头 `text-[11px] uppercase tracking-wider` secondary，
  **禁止**垂直边框与粗水平分割线，用行间距 + 行悬浮微亮区分；进度条 4px 全圆角、主色填充；状态 Badge 胶囊体 = 状态色 10–12% 透明底 + 同色文字，运行中加 4px呼吸脉冲点。行内操作按钮 `text-xs` 链接式（主操作 `--accent-blue`、危险操作`--accent-red`）。
- **弹窗 Modal**：居中玻璃浮层（`max-w-lg rounded-3xl` + 弹簧缩放淡入），遮罩`bg-black/20 backdrop-blur-md`，主界面可微缩放后退（scale 0.98）营造 Z 轴深度。右上角关闭用 `<el-icon>` 的 `Close` 图标按钮（带 `aria-label`）。关闭、取消、确认按钮齐全，危险操作红字按钮。**禁止**底部抽屉、侧滑面板或大面积截断式弹窗。

## 8. Agent 编码强制指令

1. **技术栈**：Vue 3 + TypeScript + Tailwind CSS + Motion for Vue
   （`@vueuse/motion`）+ Element Plus 图标（`@element-plus/icons-vue`）。不引入
   其他动效库或 UI 组件库。
2. **拒绝硬编码颜色**：一切颜色、圆角、阴影使用本规约令牌（第 2 节 CSS 变量或
   对应 Tailwind 扩展类），禁止 Tailwind 默认色与内联 `style` 色值。
3. **语义化 HTML**：正确使用 `<button>`、`<nav>`、`<main>`、`<section>`、
   `<table>`、`<label>` 等标签；可点击元素必须用 `<button>`，图标按钮必须带
   `aria-label`。
4. **布局系统**：CSS Grid 构建主布局（侧栏固定、顶栏固定、主内容区独立滚动）；
   列表用 Grid/Flex，表格用 `<table>`，禁止表格换行文本。
5. **禁用 `transition`/`keyframes`**：动效一律弹簧（第 4 节），唯一允许的 CSS
   过渡是 `.btn:active` 的按下缩放兜底。
6. **微交互强制化**：所有可点击元素必须有按下缩放反馈；悬浮有上浮反馈。
7. **数字纪律**：KPI 用等宽数字 + 负字距（第 3.2、3.3 节），状态用语义色。
8. **对比度与可读性**：玻璃面上正文 ≥ 4.5:1，禁止浅字浅底、深字深底。
9. **组件自包含**：同一页面的卡片、表格、弹窗遵循统一内边距与圆角节奏
   （第 2.5、2.6 节），禁止单组件特立独行。

## 9. 前端辅助开发：/impeccable

涉及页面样式、动效、布局的前端开发，应使用 impeccable skill 辅助。impeccable
是 Apple 风格设计的质量放大器，但它是**执行工艺的工具，不是设计决策的来源**；
本规约第 2–8 节始终优先，impeccable 的建议与本规约冲突时以本规约为准。

建议流程：

1. **规划**：复杂页面动手前，用 `shape` 规划信息结构与组件拆分，再对照本规约
   第 7 节组件基线落地。
2. **开发**：按本规约编码。纯样式/布局/动效类改动可用 `impeccable` 的
   `layout`、`typeset`、`animate`、`colorize` 等命令做增强，但增强结果不得违反
   令牌（第 2 节）、弹簧物理（第 4 节）与对比度（第 6 节）。
3. **质检**：页面完成后用 `audit` 做无障碍/性能/响应式检查、`critique` 做启发式
   评审、`polish` 做上线前收尾；发现的合规问题（emoji 图标、硬编码色值、CSS
   transition 等）一律回炉修复。
4. **持续**：项目接入 impeccable 的 init/document 流程（PRODUCT.md / DESIGN.md）
   有助于沉淀设计上下文；内容以本规约为准，冲突时本规约优先。

impeccable 的 context 脚本会读取 PRODUCT.md / DESIGN.md；若引入这些文件，须在
其中声明"视觉基线以《前端设计.md》为准"。

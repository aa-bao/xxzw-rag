# RAG 首个纵向切片实施计划

> **供智能体执行者：** 必须按任务逐项执行本计划，并使用复选框跟踪进度。推荐使用 `superpowers:subagent-driven-development`；也可使用 `superpowers:executing-plans` 在当前会话分批执行。

**目标：** 交付一个可运行的本机纵向切片：用户登录后创建私有知识库，通过持久化任务上传并入库一份 UTF-8 TXT 文档，随后检索该文档，并在 Vue 页面中获得带引用、可持久化的 SSE 流式回答。

**架构：** 后端采用 FastAPI、异步 SQLAlchemy 和 Alembic；登录使用服务端 Session；每个知识库索引版本对应一个嵌入式 ChromaDB Collection；Embedding 与 Chat 统一调用 OpenAI-compatible 本地模型中转。FastAPI 进程内只启动一个任务消费者领取 MySQL 文档任务。Vue 仅使用 `/api` 协议，绝不提交用户标识或对话历史。

**技术栈：** Python、uv、FastAPI、Pydantic Settings、SQLAlchemy async、Alembic、asyncmy、argon2-cffi、httpx、嵌入式 ChromaDB、LangChain text splitters、pytest、Vue 3、TypeScript、Vite、Pinia、Element Plus、Vitest、MySQL 8.4、Docker Compose。

## 全局约束

- 事实来源是 `RAG知识库系统-架构设计文档.md`、`CONTEXT.md` 以及 `docs/adr/0001-*.md` 至 `docs/adr/0027-*.md`。
- FastAPI 仅监听 `127.0.0.1:8000`；生产 Compose 仅映射 `127.0.0.1:8000:8000`，Uvicorn 固定单 worker。
- 所有 `rag_*` 表仅由 Python 与 Alembic 管理。
- 用户身份只能来自服务端 Session；客户端不得提交 `owner_user_id`、历史消息数组或知识库重绑定信息。
- 密码使用 Argon2id。浏览器只持有随机的 HttpOnly、SameSite=Strict Session Cookie；MySQL 只保存令牌 SHA-256 哈希。
- 所有知识库、文档、任务、对话和查询都必须按 `owner_user_id` 过滤；MySQL 还必须使用复合外键强制归属一致。
- 本切片唯一接受的文档格式是 UTF-8 TXT。Parser Factory 和任务接口需保留扩展能力，但不得声称已支持 PDF、DOCX 或 Markdown。
- 单文件上限为 100 MB。原始文件必须以生成的标识存放在 `upload.root_dir` 下，不得将用户提交的文件名用于磁盘路径。
- 文档任务使用 MySQL 持久化队列和单消费者。启动时先把遗留的 `running` 入库任务恢复为 `pending`，再领取新任务。
- 问答引擎只依赖 `RetrievalModule.retrieve(query, owner_user_id, kb_id, top_k)`，不得直接调用 ChromaDB。
- 知识库必须绑定 `embedding_model`、`embedding_dimension`、`active_collection` 和 `index_version`；本切片只创建版本 1，不修改索引版本。
- 检索内容一律视为不可信资料。每个来源必须有结构化边界，不能修改系统规则，也不能触发工具。
- Chat 仅允许在首个 SSE 内容输出前自动重试一次；一旦输出内容，后续失败不得自动重试。
- 助手消息状态只能按 `streaming -> completed|failed` 转换。流式半成品只保留在内存中，成功后才一次性持久化完整回答。
- 服务端是对话历史和 Token 预算截断的唯一事实来源；每个对话永久绑定一个知识库。
- 容量边界保持为最多 20 个用户、每用户 20 个知识库、全系统 100,000 个 Chunk、5 路并发 SSE、1 个文档任务消费者。
- 模型密钥、数据库密码、Session 令牌、用户文档和备份口令不得进入版本库、日志或测试夹具。

## 本切片边界

本计划只验证一条端到端主链路。以下内容必须拆分为后续计划：PDF/DOCX/Markdown 沙箱解析、管理员 Web 全生命周期、文档/知识库/用户永久删除、索引重建、备份恢复、保留策略、完整安全审计、质量与容量验收、依赖健康页面以及完整生产 UI 状态。完成本切片后，不得把架构文档第 14 节整体标记为完成。

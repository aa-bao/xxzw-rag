## 1. 适用范围与设计基调

### 1.1 适用范围

- **R1-1**：本规约适用于"想象之外"公司内部管理系统的**所有前端页面**。
- **R1-2**：技术栈固定为 **Vue 3 + TypeScript + Tailwind CSS + Motion for Vue（@vueuse/motion）**，不可更换。
- **R1-3**：新页面、新组件、页面改造**一律按本规约执行，禁止沿用历史页面的旧样式**。
- **R1-4**：设计基调：浅色模式、Apple 硬件质感（Mac Studio 风格）、玻璃拟态（Glassmorphism）、高精度数据可视化。目标不是"用 Tailwind 做出来的后台"，而是原生、有物理质感、流体的 macOS 桌面级应用。

### 1.2 绝对禁止（原文"绝对禁止"清单）

- **R1-5**：禁止传统的 Bootstrap 默认后台模板样式。
- **R1-6**：禁止 ai 味的紫色渐变（`#8B5CF6` 系、`purple-500` 系），尤其禁止大面积渐变背景搭配紫色高亮。
- **R1-7**：禁止纯黑 `#000000` 与纯白 `#FFFFFF` 作为页面背景或大面积卡片表面色。`--bg-elevated` **仅**用于顶部栏内元素、输入框、按钮等小面积高优先级表面。
- **R1-8**：禁止 emoji 与文本符号冒充图标（详见第 7 节）：UI 中任何图标、状态、按钮、占位一律用图标组件，禁止 `✅`、`⚠️`、`🚀`、`→` 等字符。

### 1.3 规则冲突优先级（1.1 优先级）

生成代码时遇到本规约内两条规则冲突，按以下优先级裁决：

1. **光效与玻璃材质**（毛玻璃、透明层）——材质错了页面质感立即崩塌；
2. **动效物理**（弹簧、可打断、按压反馈）——这是 Apple 风格区别于普通后台的核心；
3. **排版层级**（字号、字重、字距）——数值展示的精密感依赖排版；
4. **布局与语义化**——不破坏以上三者的前提下保证结构正确。

### 1.4 参考物（1.2）

- **R1-9**：视觉参考：`想象之外 Beyond Imagination Dashboard (Mac Studio Edition)` 单文件 demo。布局、配色、玻璃卡片、图表风格以其为准，但交互部分按本规约第 4 节替换为弹簧物理，**不得沿用其 CSS transition**。
- **R1-10**：动效参考：Apple Design skill（来自 WWDC *Designing Fluid Interfaces*、*The Details of UI Typography* 等，经 Emil Kowalski 翻译到 Web）。

## 2. 设计令牌（Design Tokens）

### 2.0 总则

- **R2-1**：所有颜色、字体、圆角、阴影**只允许引用令牌**。
- **R2-2**：**禁止硬编码色值**，禁止使用 `bg-blue-500`、`text-gray-400` 等 Tailwind 默认色。

### 2.1 背景令牌（逐字保留）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#F5F5F7` | 页面主背景，**全局唯一背景色** |
| `--bg-subtle` | `#FAFAFC` | 次级背景：分组、井状区域 |
| `--bg-glass` | `rgba(255, 255, 255, 0.72)` | 玻璃卡片/侧栏表面 |
| `--bg-glass-strong` | `rgba(255, 255, 255, 0.85)` | 可悬停浮层（弹窗） |
| `--bg-elevated` | `#FFFFFF` | 不透明高优先级表面（顶部栏内元素） |
| `--bg-mask` | `rgba(0, 0, 0, 0.20)` | Modal 遮罩 |
| `--glow-blue` | `rgba(219, 234, 254, 0.60)` | 背景低饱和蓝色环境光 |
| `--glow-violet` | `rgba(243, 232, 255, 0.50)` | 背景低饱和紫色环境光 |

- **R2-3**：玻璃表面与背景**必须拉开明度差**：玻璃面用 `rgba(255,255,255,…)` 白色半透明覆盖在 `#F5F5F7` 底上，自然形成可辨识的层级。
- **R2-4**：**禁止**在浅色半透明表面上再叠另一块浅色半透明表面（对比度会塌掉）。

### 2.2 边框与阴影令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--border-subtle` | `rgba(0, 0, 0, 0.06)` | 卡片描边，**全局统一** |
| `--border-strong` | `rgba(0, 0, 0, 0.10)` | 强调描边：输入框、选中态 |
| `--shadow-card` | `0 10px 30px -5px rgba(0,0,0,0.04), 0 0 1px 1px rgba(0,0,0,0.02)` | 卡片阴影 |
| `--shadow-card-hover` | `0 20px 40px -10px rgba(0,0,0,0.08), 0 0 1px 1px rgba(0,0,0,0.04)` | 卡片悬浮阴影 |
| `--shadow-modal` | `0 25px 60px -12px rgba(0,0,0,0.18), 0 0 1px 1px rgba(0,0,0,0.04)` | 弹窗阴影 |
| `--chart-grid` | `rgba(0,0,0,0.04)` | 图表水平网格线 |

- **R2-5**：卡片描边统一 1px `--border-subtle`，**不用**纯白高光描边。
- **R2-6**：阴影统一弥散多层（ambient + 1px contact），**禁止**大范围 `box-shadow` 硬投影。

### 2.3 文本令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--text-primary` | `#1D1D1F` | 主文本、KPI 大数字 |
| `--text-secondary` | `#86868B` | 次级文本、标签、图例 |
| `--text-tertiary` | `#AEAEB2` | 占位符、禁用、时间轴刻度 |

- **R2-7**：文本全部落在不透明深灰上，**禁止**在玻璃面使用浅灰/白色文本。

### 2.4 品牌与状态色令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--accent-blue` | `#007AFF` | 主操作色、选中态、图表主线 |
| `--accent-indigo` | `#5856D6` | 次图表线、信息标记 |
| `--accent-orange` | `#FF9500` | 警告、中性图表线 |
| `--accent-green` | `#34C759` | 成功、在线、正向趋势 |
| `--accent-red` | `#FF3B30` | 错误、危险操作 |

分层汇总表格专用语义色：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--summary-date-bg` | `#EDF4FF` | 日期汇总行 |
| `--summary-date-hover` | `#E4EEFF` | — |
| `--summary-date-border` | `#CDDCFA` | — |
| `--summary-date-text` | `#153D86` | — |
| `--summary-group-bg` | `#F6F8FB` | 二级分组小计行 |
| `--summary-group-hover` | `#EEF2F7` | — |
| `--summary-group-border` | `#E1E6ED` | — |
| `--summary-group-text` | `#303B4D` | — |

- **R2-8**：**禁止**在组件内额外引入自定义色。通用状态优先复用现有品牌与状态色；分层汇总表格**只允许**使用上方 `--summary-*` 语义令牌。
- **R2-9**：需要其他新语义时，必须先在本节扩展令牌，**禁止**在页面或组件中临时硬编码。

### 2.5 圆角令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-lg` | `0.875rem`（14px） | 按钮、输入框、标签 |
| `--radius-2xl` | `1rem`（16px） | 次级面板 |
| `--radius-3xl` | `1.25rem`（20px） | 卡片、侧栏条目、弹窗 |
| `--radius-full` | `9999px` | 胶囊：Badge、开关、状态点 |

- **R2-10**：圆角沿连续曲率走向，**禁止** `rounded-sm`/`rounded-md` 等小圆角破坏观感。

### 2.6 间距

- **R2-11**：统一按 **4px 网格**递进：`4 / 8 / 12 / 16 / 20 / 24 / 32`。
- **R2-12**：卡片内边距 `p-5`（20px），页面主区边距 `p-6`（24px），卡片间距 `gap-5`（20px）。
- **R2-13**：卡片与文字对齐时，内边距**必须**与相邻元素的 x 轴 padding 一致，杜绝文字"顶到卡片边"。

### 2.7 图标

- **R2-14**：图标统一使用 **Element Plus 图标库**（`@element-plus/icons-vue`）。图标是 UI 的一等公民，**禁止**用 emoji、字符符号或网络图片代替。
- **R2-15**：图标用 `<el-icon>` 包裹，用 `currentColor` 继承所在元素文本色，**禁止**固定为某个色值。库内图标为填充风格（`fill="currentColor"`）；需要描边/线性风格时，用内联 SVG（`fill="none"` + `stroke="currentColor"`）替代。
- **R2-16**：尺寸统一：按钮内 **16px**，卡片图标徽标内 **20px**，空状态 **48px**（用 `font-size` 控制）。行内图标与文字垂直居中，间距 **6px**。
- **R2-17**：库内找不到语义匹配的图标时，内联一个自定义 SVG 描边图标（heroicons 线性风格，`fill="none"` + `stroke="currentColor"`），**不得降级为 emoji**。
- **R2-18**：无意义装饰性图标（仅为了"有图标"而加）**禁止**出现。

## 3. 排版与字体

### 3.1 字体栈

- **R3-1**：字体栈固定为：

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display",
             "PingFang SC", "Helvetica Neue", sans-serif;
```

- **R3-2**：系统字体优先，优先顺序**固定**为 `-apple-system` → `BlinkMacSystemFont` → SF Pro Display → PingFang SC，**禁止**引入 Inter、Roboto 等自定义字体。

### 3.2 数字与等宽数字

- **R3-3**：**所有数值型数据**（KPI、百分比、FLOPS、延时、时间戳）**强制**：

```css
font-variant-numeric: tabular-nums;
```

- **R3-4**：目的：防止数字实时刷新时宽度跳动。
- **R3-5**：时间与阈值标注（如 `⌘K`）用等宽字体 `SF Mono, Menlo, Monaco, monospace`。

### 3.3 字距与行高（tracking / leading）

- **R3-6**：字距随字号变化，**禁止**全文统一 `letter-spacing`。

| 用途 | 字号 | 字距 | 行高 |
|---|---|---|---|
| 页面标题 H1 | `text-2xl`（24px） | `-0.02em` | 1.2 |
| 卡片标题 H3 | `text-base`（16px） | `-0.01em` | 1.3 |
| 正文 / 描述 | `text-xs`~`text-sm` | `0` | 1.5 |
| 微型标签（FLOPS、状态） | `text-[10px]`~`text-xs` | `0.03em`，大写 | 1.4 |

- **R3-7**：字号层级固定为：微型标签 `10-12px` → 正文 `12-14px` → 卡片标题 `16px` → 页面标题 `24px`。
- **R3-8**：**禁止** KPI 数值用小于 `text-2xl` 的字号。

### 3.4 语义化排版

- **R3-9**：卡片内文字至少两级：`text-secondary` 标签 + `text-primary` 数值/标题。
- **R3-10**：层级靠**字重**拉开（`font-medium`/`font-bold`/`font-black`），不只靠字号。
- **R3-11**：数值前导趋势（`↑ 12.5%`）用 `--accent-green` 的 `font-bold` 小字，不带箭头以外的符号。

## 4. 动效与交互物理（Apple 法则）

### 4.0 最高优先级指令

- **R4-1**：**最高优先级指令：所有交互元素禁止使用 CSS `transition` 和 `@keyframes` 实现动效，必须使用弹簧物理（Spring Physics，Motion for Vue）。** 唯一例外是第 4.5 节的按下反馈 `:active` 变换，以及第 6 节减弱动态效果后的兜底。
- **R4-2**：设计语义使用**临界阻尼 / 轻微回弹**与**响应时间**描述；代码统一映射到 Motion for Vue 的 `bounce` 与 `duration`，**禁止同一项目混用两套参数口径**。
- **R4-3**：参数含义：`bounce: 0` 表示临界无回弹，`bounce: 0.2` 表示轻微回弹；`duration` 取 `0.3–0.4` 作为响应快慢配置，不作为 CSS 固定时长。

### 4.1 默认动效参数（逐字保留）

```ts
// Motion for Vue
import { useSpring } from '@vueuse/motion';

// 临界阻尼，优雅快速落位：弹窗出现、菜单展开、数字跳动
useSpring(el, {
  y: 0,
  type: 'spring', bounce: 0, duration: 0.4,
});

// 带动量交互（拖拽松手/滑动后）：允许轻微回弹，体现惯性
useSpring(el, {
  y: target,
  type: 'spring', bounce: 0.2, duration: 0.4,
});
```

| 交互 | `bounce` | `duration` |
|---|---|---|
| 默认 UI（出现/消失/换位） | `0` | `0.3–0.4` |
| 底部抽屉 / 侧滑面板 | `0.2` | `0.3` |
| 旋转 | `0.2` | `0.4` |
| 拖拽松手后的惯性回弹 | `0.2` | `0.4` |

### 4.2 可打断性（最核心）

- **R4-4**：任何动画必须随时可打断、可重定向。
- **R4-5**：动画**永远从当前屏幕上的真实位置**开始（presentation value），**禁止**从目标值/逻辑值起步，否则会产生可见跳变。
- **R4-6**：弹窗关闭动画进行中用户再次点击，**必须**立即从当前位置反向弹回，不能等待播完或生硬跳回起点。
- **R4-7**：拖拽手势反转时，速度要**混合过渡**（spring 库带速度重定向），不能硬切造成"撞墙"感。
- **R4-8**：手势路径全程**不得锁定输入**。

### 4.3 响应性与直接操控

- **R4-9**：**按下即反馈**：视觉反馈在 `pointerdown` / `:active` 瞬间触发，**禁止**等待 `click` 抬起。
- **R4-10**：**按压缩放**：所有可点击卡片、按钮按下瞬间轻微缩小。

```css
/* CSS 兜底（作用于 active 瞬间，随后由弹簧接管位移） */
.btn:active { transform: scale(0.97); }
```

- **R4-11**：拖拽元素用 Pointer Events + `setPointerCapture` 保证 1:1 跟手，并记录 grab offset 与速度历史；松手时把释放速度交给弹簧作为初始速度（seamless 速度交接）。
- **R4-12**：列表、面板、抽屉用**动量投影**落位（释放速度投影出目标停靠点，再吸附最近吸附点），**禁止**从松手点硬吸附最近边界。

### 4.4 触觉反馈分层（逐字保留）

| 反馈 | 触发时机 | 实现 |
|---|---|---|
| 按压缩放 | `pointerdown` | `:active scale(0.97)` |
| 悬停上浮 | `pointerenter` | 弹簧 `y: -2px` + 阴影加深 |
| 内容进入 | 路由/挂载 | 弹簧 `y: 8px → 0` + `opacity` 淡入 |
| 数值跳动 | 数据更新 | 弹簧数字滚动 / `tabular-nums` 稳宽 |

### 4.5 悬停

- **R4-13**：卡片悬浮统一：弹簧上浮 `y: -2px`，阴影由 `--shadow-card` 过渡到 `--shadow-card-hover`，描边不透明度不变。
- **R4-14**：**禁止**悬浮时整体放大（scale 仅用于按下）或改变背景色。

### 4.6 配置类交互

- **R4-15**：工具栏入口与功能界面**一一对应**。
- **R4-16**：视图、分组、排序、行高、填色使用工具栏下方的**主配置面板**；字段数量较少时**允许**使用锚定在入口下方的轻量浮层；筛选入口直接滚动并聚焦页面内固定的账号、品类、开始日期、结束日期筛选区，不重复创建配置面板。
- **R4-17**：**禁止**多个看似不同的按钮只打开同一个泛化面板，也**禁止**出现只能展示、不能修改的"假配置"。
- **R4-18**：当前打开的入口**必须**有明确选中态；再次点击同一入口应关闭面板，切换其他入口时直接替换面板，**不叠加多个浮层**。
- **R4-19**：非中断式主配置使用工具栏下方的内联配置面板，**不滥用 Modal**。
- **R4-20**：主面板右上角提供醒目的"关闭"文字 + `<el-icon><Close /></el-icon>`。字段轻量浮层提供 Close 图标。两种形态都**必须**支持：再次点击当前入口、切换到其他入口和 `Esc` 关闭；切换入口时原位替换，不叠层。
- **R4-21**：配置采用即时生效时，"关闭"只退出面板、**不回滚**已生效配置；用户通过"恢复默认"撤销个性化设置。需要确认后才生效的中断式任务才使用 Modal 的"取消 / 确认"语义。
- **R4-22**：配置应即时预览并明确说明持久化范围。若只保存在当前浏览器，**必须写明**；若保存为视图，**必须**能从视图标签重新打开并恢复全部配置。
- **R4-23**：每个配置界面至少包含：当前状态、可操作控件、恢复默认入口、禁用状态和结果反馈。网络提交**必须**有提交中状态并**防止重复提交**。
- **R4-24**：分组字段**不得重复**；排序**必须**支持不排序、升序、降序；字段配置至少保留一列；名称输入**必须**限制长度并校验空值、内置名称冲突和重名。
- **R4-25**：自定义视图保存的完整配置集合**固定**为：账号/品类/开始日期/结束日期筛选、可见字段及列宽、一级与二级分组、单字段排序及方向、行高档位、品类标签颜色。重新打开命名视图时**必须**恢复该集合。
- **R4-26**：分组最多两级；排序只允许一个字段；行高固定为"紧凑 / 标准 / 舒适"三档；填色只作用于品类 Badge，不改变整行底色；字段配置负责显隐，不在本期承担列拖拽排序或冻结。
- **R4-27**：即时配置先写入当前浏览器本地设置；命名视图提交到服务端并按当前租户、部门和用户隔离。保存失败时保留当前预览、不覆盖服务端版本，并提供可重试的错误反馈。
- **R4-28**：自定义视图**必须**支持"保存为新视图"和"更新当前视图"；内置视图不可更新或删除，只能另存为自定义视图。
- **R4-29**：删除当前视图属于危险操作，需二次确认；成功后优先回到"店铺总数据"，无权限时回到第一个授权的内置视图。删除非当前视图不改变当前页面。
- **R4-30**：视图名称先执行 `trim`，最大 **40 个字符**；前端至少按修剪后的完整名称预检空值、内置名称冲突和重名，最终唯一性以服务端当前租户/部门/用户作用域校验为准。

## 5. 玻璃拟态材质

### 5.1 玻璃面板

```css
.glass-surface {
  background: var(--bg-glass);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid var(--border-subtle);
  box-shadow: var(--shadow-card);
}
```

- **R5-1**：**侧栏、顶栏、卡片、弹窗**统一用该玻璃表面；顶栏玻璃 `blur(20px)` 高度透出下方滚动内容。
- **R5-2**：弹窗等浮层用 `--bg-glass-strong`，模糊更强、阴影更深（`--shadow-modal`）。
- **R5-3**：表面越重，层级越接近结构边界（侧栏比按钮重）；**禁止**在另一块浅色玻璃上叠浅色玻璃。

### 5.2 背景环境光

- **R5-4**：主内容区背后放 2–3 个弥散光斑（`blur: 120px`、全圆角、`pointer-events: none`），颜色**只引用** `--glow-blue` 与 `--glow-violet`，营造玻璃折射的光线感。
- **R5-5**：**禁止**直接使用 Tailwind 默认颜色类或高饱和光斑。

## 6. 无障碍与边界

- **R6-1**：**减弱动态效果**：监听 `@media (prefers-reduced-motion: reduce)`，所有弹簧/位移动画替换为 **200ms** 透明度交叉淡入淡出，去掉回弹与位移动画。
- **R6-2**：**降低透明度**：`@media (prefers-reduced-transparency: reduce)` 时玻璃表面改为近实底（背景不透明度升至 **0.9+**，`backdrop-filter: none`）。
- **R6-3**：**对比度**：玻璃面上正文对背景对比度 **≥ 4.5:1**。玻璃表面保持浅色 + 深灰文本，**禁止**浅灰/白字；必要时给悬停浮层加深阴影分隔背景。
- **R6-4**：尺寸单位用 `rem`，随用户文字大小缩放布局；不做纯 px 硬排。
- **R6-5**：配置面板使用语义化 `role="region"` 与可读的 `aria-label`；图标按钮**必须**具备准确的 `aria-label`，不能只依赖图形表达用途。
- **R6-6**：默认查询**只加载当前业务日期的数据**。业务日期按自然日 `00:00–23:59:59` 和主系统传入或项目配置的 IANA 时区计算；时区缺失或无效时统一回退 `Asia/Shanghai`。
- **R6-7**：其他日期、日期区间和历史数据**必须**由用户查询后按需加载，**禁止**首页预载全部历史数据。
- **R6-8**：页面跨午夜时**不得覆盖**用户已选筛选条件；下次进入页面或执行"重置"时重新计算当前业务日期。
- **R6-9**：大数据表必须分页、分日期加载或虚拟化；分组展开/收起只改变当前已加载数据的呈现状态，**不得**因一次折叠重新请求全部数据。

## 7. 核心组件规范

组件基线（数据示例沿用系统业务）：

### 7.1 指标卡 StatCard

- **R7-1**：结构顺序：标签（`text-xs` secondary）→ 图标徽标（**28px** 圆角方，色相 **10%** 透明底 + 同色 `<el-icon>` 图标）→ 数值（`text-2xl font-black` 主色）→ 趋势（绿/橙 `font-bold` 小字）→ 底部迷你贝塞尔趋势线（同色 **2.5px** 圆头描边）。
- **R7-2**：整卡可点击，按 4.5 悬停（弹簧上浮 `y: -2px` + 阴影加深，禁止放大）。
- **R7-3**：图标不得用 emoji 或字符。

### 7.2 图表卡 ChartCard

- **R7-4**：纯 SVG 平滑贝塞尔样条，面积渐变（顶部同色 20% 到 0%），仅使用 `--chart-grid` 的水平虚线网格，**禁止**垂直网格线。
- **R7-5**：图例 = 色点 + `text-xs` 标签。
- **R7-6**：折线图悬浮召唤垂直十字线与玻璃 Tooltip，Tooltip 弹簧**磁吸**最近数据点。

### 7.3 数据表格 DataTable

- **R7-7**：纯英文微型表头可使用 `text-[11px] uppercase tracking-wider`；中文业务表头使用 `text-[13px]`～`text-sm`、中等字重且不强制大写。
- **R7-8**：**禁止**垂直边框与粗水平分割线，用行间距 + 行悬浮微亮区分。
- **R7-9**：进度条 **4px** 全圆角、主色填充。
- **R7-10**：状态 Badge 胶囊体 = 状态色 **10–12%** 透明底 + 同色文字，运行中加 **4px** 呼吸脉冲点。
- **R7-11**：行内操作按钮 `text-xs` 链接式（主操作 `--accent-blue`、危险操作 `--accent-red`）。

#### 分层数据表（日期汇总 / 分组小计 / 明细）

- **R7-12**：分层数据表**必须**同时依靠底色、文字、字重和标签建立层级，**禁止**只靠加粗或轻微灰底区分。
  1. **日期汇总行**：使用 `--summary-date-*`，显示"日期汇总"标签，日期与汇总数字使用深蓝色和等宽数字；
  2. **二级分组小计行**：使用 `--summary-group-*`，显示"分组小计"标签，名称和数字使用石墨色半粗体；
  3. **普通明细行**：使用普通表面色与常规字重，悬停时才出现微亮背景。
- **R7-13**：日期汇总名称从表格内容起点对齐，二级分组在其基础上**缩进 24px**。
- **R7-14**：分组名称**不得**因复选框占位而漂移到数据列中部。
- **R7-15**：汇总标签不能挤压名称，长名称使用省略号，条数保持可见。

### 7.4 配置工作台 ConfigPanel

- **R7-16**：工具栏下方的单层内联面板，使用 `rounded-2xl`、清晰标题、说明、正文区和底部持久化提示。
- **R7-17**：每个工具栏入口只展示对应控件：视图、分组、排序、行高、填色互不混杂。
- **R7-18**：主配置面板提供"关闭"文字 + Close 图标；字段轻量浮层至少提供 Close 图标。
- **R7-19**：所有操作实时影响目标表格，并提供恢复默认、禁用、加载、成功、失败和危险确认状态。

### 7.5 弹窗 Modal

- **R7-20**：居中玻璃浮层（`max-w-lg rounded-3xl` + 弹簧缩放淡入），遮罩引用 `--bg-mask` 并使用 `backdrop-blur-md`，主界面可微缩放后退（scale **0.98**）营造 Z 轴深度。
- **R7-21**：右上角关闭用 `<el-icon>` 的 `Close` 图标按钮（带 `aria-label`）。
- **R7-22**：关闭、取消、确认按钮齐全，危险操作红字按钮。
- **R7-23**：**禁止**底部抽屉、侧滑面板或大面积截断式弹窗。

## 8. Agent 编码强制指令

- **R8-1**：**技术栈**：Vue 3 + TypeScript + Tailwind CSS + Motion for Vue（`@vueuse/motion`）+ Element Plus 图标（`@element-plus/icons-vue`）。**不引入**其他动效库或 UI 组件库。
- **R8-2**：**拒绝硬编码颜色**：一切颜色、圆角、阴影使用本规约令牌（第 2 节 CSS 变量或对应 Tailwind 扩展类），**禁止** Tailwind 默认色与内联 `style` 色值。
- **R8-3**：**语义化 HTML**：正确使用 `<button>`、`<nav>`、`<main>`、`<section>`、`<table>`、`<label>` 等标签；可点击元素必须用 `<button>`，图标按钮必须带 `aria-label`。
- **R8-4**：**布局系统**：CSS Grid 构建主布局（**侧栏固定、顶栏固定、主内容区独立滚动**）；列表用 Grid/Flex，表格用 `<table>`，**禁止表格换行文本**。（注：此为文档中唯一的导航/布局结构性要求）
- **R8-5**：**禁用 `transition`/`keyframes`**：动效一律弹簧（第 4 节），唯一允许的 CSS 过渡是 `.btn:active` 的按下缩放兜底。
- **R8-6**：**微交互强制化**：所有可点击元素必须有按下缩放反馈；悬浮有上浮反馈。
- **R8-7**：**数字纪律**：KPI 用等宽数字 + 负字距（第 3.2、3.3 节），状态用语义色。
- **R8-8**：**对比度与可读性**：玻璃面上正文 ≥ 4.5:1，禁止浅字浅底、深字深底。
- **R8-9**：**组件自包含**：同一页面的卡片、表格、弹窗遵循统一内边距与圆角节奏（第 2.5、2.6 节），**禁止**单组件特立独行。
- **R8-10**：**禁止伪功能**：工具栏、配置按钮和菜单节点只要以可用状态展示，就必须完成真实数据绑定与完整操作链路；规划中能力必须明确标记并禁用进入。
- **R8-11**：**配置可恢复**：所有用户配置必须能恢复默认；需要跨会话复用的配置应保存为命名视图，并处理保存失败、更新、重名和删除确认。

37. **R6-8**：页面跨午夜时不得覆盖用户已选筛选条件。
38. **R6-9**：分组展开/收起不得因一次折叠重新请求全部数据。
39. **R7-4**：禁止垂直网格线（图表仅用 `--chart-grid` 水平虚线网格）。
40. **R7-8**：禁止垂直边框与粗水平分割线（表格用行间距 + 行悬浮微亮区分）。
41. **R7-12**：分层数据表禁止只靠加粗或轻微灰底区分层级（须底色+文字+字重+标签四要素）。
42. **R7-14**：分组名称不得因复选框占位而漂移到数据列中部。
43. **R7-15**：汇总标签不能挤压名称（长名称用省略号，条数保持可见）。
44. **R7-23**：禁止底部抽屉、侧滑面板或大面积截断式弹窗（Modal 规范）。
45. **R8-1**：不引入其他动效库或 UI 组件库（技术栈固定）。
46. **R8-2**：禁止 Tailwind 默认色与内联 `style` 色值。
47. **R8-4**：禁止表格换行文本。
48. **R8-5**：禁止使用 `transition`/`keyframes`（唯一允许的 CSS 过渡是 `.btn:active` 按下缩放兜底）。
49. **R8-8**：禁止浅字浅底、深字深底（对比度 ≥ 4.5:1）。
50. **R8-9**：禁止单组件特立独行（内边距与圆角节奏统一）。
51. **R8-10**：禁止伪功能（以可用状态展示就必须真实数据绑定 + 完整操作链路；规划中能力须标记并禁用）。
52. **R9-4**：impeccable 增强结果不得违反令牌（第 2 节）、弹簧物理（第 4 节）与对比度（第 6 节）。
53. **R9-5**：合规问题（emoji 图标、硬编码色值、CSS transition 等）一律回炉修复。

## 13. 本文件要点速览

以下为全文档最关键的强制要求（30 条）：

1. 技术栈固定：Vue 3 + TypeScript + Tailwind CSS + Motion for Vue（@vueuse/motion）+ Element Plus 图标（@element-plus/icons-vue），不引入其他动效库或 UI 组件库。
2. 设计基调：浅色模式、Apple 硬件质感（Mac Studio 风格）、玻璃拟态、高精度数据可视化；新页面、新组件、页面改造一律按本规约执行。
3. 绝对禁止 emoji/文本符号冒充图标（✅⚠️🚀→ 等）；UI 图标、状态、按钮、占位一律用图标组件。
4. 禁止纯黑 #000000 与纯白 #FFFFFF 作页面背景或大面积卡片表面；--bg-elevated 仅限顶部栏内元素、输入框、按钮等小面积表面。
5. 禁止 Bootstrap 默认后台模板样式、ai 味紫色渐变（#8B5CF6 系、purple-500 系）、大面积渐变+紫色高亮。
6. 所有颜色/字体/圆角/阴影只允许引用令牌，禁止硬编码色值和 Tailwind 默认色（bg-blue-500、text-gray-400 等）。
7. 背景令牌：--bg-base #F5F5F7（全局唯一背景色）、--bg-subtle #FAFAFC、--bg-glass rgba(255,255,255,0.72)、--bg-glass-strong rgba(255,255,255,0.85)、--bg-mask rgba(0,0,0,0.20)、光斑 --glow-blue rgba(219,234,254,0.60)/--glow-violet rgba(243,232,255,0.50)。
8. 边框阴影：--border-subtle rgba(0,0,0,0.06)（卡片描边统一 1px）、--border-strong rgba(0,0,0,0.10)、三档弥散多层阴影（card/hover/modal），禁止大范围硬投影。
9. 文本令牌：#1D1D1F 主文本、#86868B 次级、#AEAEB2 占位/禁用；禁止在玻璃面用浅灰/白字。
10. 品牌色：#007AFF 蓝（主操作）、#5856D6 indigo、#FF9500 橙（警告）、#34C759 绿（成功）、#FF3B30 红（错误/危险）；禁止组件内额外引入自定义色，分层汇总表只允许 --summary-* 令牌。
11. 圆角：--radius-lg 0.875rem(14px)/--radius-2xl 1rem(16px)/--radius-3xl 1.25rem(20px)/--radius-full 9999px；禁止 rounded-sm/rounded-md。
12. 间距 4px 网格：4/8/12/16/20/24/32；卡片内边距 p-5(20px)、页面主区 p-6(24px)、卡片间距 gap-5(20px)；卡片内边距须与相邻元素 x 轴 padding 一致。
13. 字体栈固定 -apple-system → BlinkMacSystemFont → SF Pro Display → PingFang SC（"Helvetica Neue", sans-serif 兜底）；禁止 Inter、Roboto 等自定义字体。
14. 所有数值型数据（KPI、百分比、FLOPS、延时、时间戳）强制 font-variant-numeric: tabular-nums；时间/阈值标注用 SF Mono, Menlo, Monaco, monospace。
15. 排版：H1 text-2xl(24px) 字距 -0.02em 行高 1.2；H3 text-base(16px) -0.01em 1.3；正文 text-xs~sm 0 1.5；微型标签 10-12px 0.03em 大写 1.4；禁止全文统一 letter-spacing；禁止 KPI 小于 text-2xl。
16. 最高优先级指令：所有交互元素禁止 CSS transition 与 @keyframes，必须用 Motion for Vue 弹簧物理；唯一例外为 .btn:active 按下缩放兜底与 prefers-reduced-motion 兜底。
17. 动效参数口径统一：bounce:0 临界无回弹、bounce:0.2 轻微回弹，duration 0.3–0.4；默认 UI bounce 0 / duration 0.3–0.4，抽屉/侧滑 bounce 0.2/0.3，旋转与拖拽惯性 bounce 0.2/0.4。
18. 动画必须可打断：永远从当前屏幕真实位置起步（禁止从目标值起步）；弹窗关闭中再次点击须立即反向弹回；拖拽反转速度须混合过渡；手势全程不得锁定输入。
19. 按下即反馈于 pointerdown/:active（禁止等 click）；所有可点击卡片/按钮按下 scale(0.97)；悬停弹簧上浮 y:-2px + 阴影加深（禁止悬浮放大或改背景色）；内容进入 y:8px→0 + opacity 淡入。
20. 拖拽用 Pointer Events + setPointerCapture 保证 1:1 跟手并记录速度历史，松手把速度交给弹簧；列表/面板/抽屉动量投影落位，禁止从松手点硬吸附。
21. 配置交互：工具栏入口与功能一一对应；视图/分组/排序/行高/填色用工具栏下方主配置面板，字段用轻量浮层，筛选直接滚动聚焦固定筛选区；禁止泛化面板与"假配置"；入口有选中态，切换入口原位替换不叠层。
22. 配置面板关闭方式：主面板"关闭"文字 + Close 图标，字段浮层 Close 图标；均须支持再次点击入口、切换入口和 Esc 关闭；即时生效配置"关闭"不回滚，撤销走"恢复默认"。
23. 视图规则：名称 trim 后最大 40 字符；保存集合固定为筛选/字段及列宽/一二级分组/单字段排序/行高三档（紧凑/标准/舒适）/品类标签颜色；支持"保存为新视图""更新当前视图"；内置视图不可改删只能另存；删除当前视图二次确认，成功后优先回"店铺总数据"；服务端按租户/部门/用户作用域校验唯一性。
24. 玻璃表面：.glass-surface = var(--bg-glass) + backdrop-filter blur(20px) saturate(180%) + 1px --border-subtle + --shadow-card；侧栏/顶栏/卡片/弹窗统一使用；浮层用 --bg-glass-strong + --shadow-modal；禁止浅色玻璃叠浅色玻璃。
25. 背景环境光：主内容区背后 2–3 个光斑（blur:120px、全圆角、pointer-events:none），只引用 --glow-blue/--glow-violet，禁止 Tailwind 默认色类或高饱和光斑。
26. 无障碍：prefers-reduced-motion 时全部弹簧/位移换 200ms 透明度交叉淡入淡出；prefers-reduced-transparency 时玻璃面背景不透明度升至 0.9+ 且 backdrop-filter:none；正文对比度 ≥ 4.5:1；单位用 rem；配置面板 role="region" + aria-label，图标按钮必须有 aria-label。
27. 数据边界：默认只加载当前业务日期（自然日 00:00–23:59:59，IANA 时区，缺失回退 Asia/Shanghai）；历史数据须用户查询按需加载，禁止首页预载；跨午夜不得覆盖用户筛选；大表分页/分日期/虚拟化，折叠分组不得重新请求全部数据。
28. 组件：StatCard（28px 圆角方徽标 10% 透明底、text-2xl font-black 数值、2.5px 圆头迷你趋势线、整卡可点击）；ChartCard（纯 SVG 贝塞尔、面积渐变 20%→0%、仅水平虚线网格禁垂直网格线、Tooltip 弹簧磁吸数据点）。
29. DataTable：禁垂直边框与粗水平分割线；表头英文 text-[11px] uppercase tracking-wider / 中文 text-[13px]~sm 中字重不强制大写；进度条 4px 全圆角；Badge 胶囊 = 状态色 10–12% 透明底 + 同色文字，运行中 4px 呼吸脉冲点；分层表日期汇总行 --summary-date-*（"日期汇总"标签、深蓝等宽数字）、分组小计行 --summary-group-*（"分组小计"标签、石墨色半粗体），二级分组缩进 24px。
30. Modal：居中玻璃浮层 max-w-lg rounded-3xl + 弹簧缩放淡入，遮罩 --bg-mask + backdrop-blur-md，主界面 scale 0.98 后退；右上角 Close 图标按钮带 aria-label；危险操作红字；禁止底部抽屉/侧滑面板/大面积截断式弹窗。
31. 布局：CSS Grid 主布局，侧栏固定、顶栏固定、主内容区独立滚动；可点击元素必须用 <button>，图标按钮带 aria-label；禁止表格换行文本。
32. 禁止伪功能：工具栏、配置按钮、菜单节点以可用状态展示就必须真实数据绑定 + 完整操作链路；规划中能力明确标记并禁用。
33. impeccable 仅作执行工艺工具：本规约第 2–8 节优先，冲突以本规约为准；增强不得违反令牌/弹簧物理/对比度；audit/critique/polish 发现的合规问题（emoji 图标、硬编码色值、CSS transition）一律回炉修复；引入 PRODUCT.md/DESIGN.md 须声明"视觉基线以《12-前端页面设计规范.md》为准"。
34. 验收：宽窄屏均无页面级横向溢出（宽表仅容器内滚动）；控制台无错误；加载/空/错误/禁用/无权限状态均有反馈；reduced-motion/transparency 下功能完整可用；数值 tabular-nums 且汇总与明细求和一致。

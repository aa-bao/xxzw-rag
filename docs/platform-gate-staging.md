# 平台门禁顺序：G6 无副作用 Smoke 与 G7 受控灰度（规范 11 §9/§10）

## G6 首次生产发布（只允许无副作用验证）

首次生产发布只允许以下验证动作，**禁止任何业务写入**：

- 入口与 SSO 验证：主系统容器进入项目、一次授权码 + PKCE 兑换、独立项目会话建立。
- 只读验证：目录/配置摘要、权限字符核对、`dataScope` 只读查询。
- 探针：`/platform/health`、`/platform/readiness`、`/platform/version`（响应不含密钥）。
- Agent/制品检查：无执行器组件，仅核对组件镜像 Digest 与运行版本。
- 无副作用任务：`DRY_RUN` 或只读任务。

**G6 禁止**：写生产业务结果、保存或发布商品、打开未授权浏览器窗口、修改店铺/账号/价格/库存、
自动重跑历史 `UNKNOWN` 任务。

## G7 受控灰度阶梯（逐级扩大）

1. 单租户/单部门
2. 单店铺（本项目无店铺概念，按业务域映射为单知识库/单文档集合）
3. 单业务项
4. 单执行器并发 1（本项目无 Windows 执行器，跳过此项并在门禁报告中如实声明）
5. 项目默认批次
6. 全量配置

每级验证清单：

- 业务结果与 Task 关联正确（本应用无平台 Task 下发，验证请求/结果幂等语义即可）。
- 无重复副作用（`businessRequestId + Idempotency-Key` 防重复创建；结果重复提交返回同一 resultId）。
- 取消/超时/进程丢失形成确定或保守终态（UNKNOWN 不自动重放）。
- 日志/截图/报告不泄密（`TEST_SECRET_SENTINEL` 与认证头脱敏）。
- 资源释放且节点恢复可用（镜像资源边界已声明，无常驻 Worker 泄漏）。
- 回滚点有效（每次发布前冻结目标 Release 与回滚点）。

## 验收结论判定

- G0–G6 全部通过才具备生产接入资格；G7 完成受控业务验证后才能扩大运营范围。
- 发布状态：CI 全绿 ≠ 已上线；Release 停在 `REGISTERED` 不会自动成为运行版本，必须平台侧
  显式发起 `RELEASE`（权限 `rpa:project-application:deploy`）并走完 12 步部署状态机。
- 本仓库可执行部分已完成并通过本地门禁；真实发布与黑盒验收需平台侧 Controller 凭据。
